## 🔍 Overview

FinAI is an AI-first personal finance dashboard that goes beyond simple expense tracking. It analyzes behavioral spending patterns, provides a composite financial health score, offers an AI financial coach powered by Gemini, and keeps users motivated through gamification — all wrapped in a sleek, responsive UI with dark/light theme support.

## ✨ Features

### 📊 Dashboard
- **Overview cards** — Total balance, monthly spending, savings rate, and active goals at a glance.
- **Spending breakdown** — Interactive pie chart by category (Food, Shopping, Transport, etc.).
- **Weekly spending trend** — Bar chart showing the last 7 days of spending.
- **Goal progress** — Visual progress bars for the top savings goal.
- **Recent transactions** — Latest 6 expenses with merchant, category, and amount.
- **Smart alerts** — AI-generated nudges (e.g., "You've spent 80% of your food budget").
- **Weekly report card** — AI-generated weekly summary with insights.
- **Health score widget** — Circular gauge linking to the full Financial Health page.

### 🏥 Financial Health Score
- **Composite 0–100 metric** calculated from:
  - Savings rate
  - Budget adherence
  - Spending consistency
  - Subscription management
  - Goal progress
- **AI-powered tips** — Personalized, actionable advice generated by Gemini AI.
- **Historical trend** — Track how your score changes over time.

### 🎯 Smart Goals
- Create savings goals with name, target amount, deadline, category, priority, and emoji icon.
- **Progress tracking** — Visual progress bars and bar charts.
- CRUD operations with real-time updates.
- Categories: Travel, Emergency, Education, Retirement, Home, etc.

### 💸 Expense Tracking
- Log expenses with merchant, amount, category, date, payment method, and optional notes.
- **Receipt scanner** — Upload a receipt photo; AI extracts merchant, amount, and category automatically.
- Filter and sort transactions.
- Category-based spending visualization.

### 💳 My Cards
- Link debit/credit cards with bank name, last four digits, cardholder name, card network (Visa/Mastercard/Amex/RuPay), and card type.
- **Visual card previews** with customizable colors and regional flags.
- Support for international and Indian card networks.

### 📦 Subscription Manager
- Track recurring subscriptions (Netflix, Spotify, gym, etc.).
- **Next billing date** alerts.
- Monthly/yearly cycle tracking.
- Category-based organization.
- AI suggestions to cut unnecessary subscriptions.

### 📁 Budgets
- Set monthly spending limits per category.
- **Budget adherence tracking** — Visual progress bars showing usage vs. limit.
- AI alerts when approaching or exceeding budget limits.

### 📈 Insights (AI Spending Analysis)
- **Category breakdown** — Where your money goes.
- **Trend analysis** — Month-over-month spending patterns.
- AI-generated insights powered by Gemini.

### 🤖 AI Financial Coach (Assistant)
- **Context-aware chat** — The AI knows your expenses, goals, budgets, and subscriptions.
- **Financial context badges** — Shows how many expenses, goals, and budgets the AI is analyzing.
- Suggested prompts for common queries.
- Chat history persistence in the database.
- Powered by Gemini AI via Lovable AI gateway.

### 🧠 Behavioral Spending Analysis
- **Spending personality detection** — Identifies patterns like Night Owl Spender, Impulse Shopper, Weekend Warrior.
- **Time-of-day analysis** — When you spend the most.
- **Weekend vs. weekday** spending trends.
- **Impulse buy tracking** — Flags potential impulse purchases.
- **AI behavioral nudges** — Personalized suggestions to improve habits.

### 👨‍👩‍👧‍👦 Family Budget
- **Create family groups** with invite codes.
- **Join groups** via invite code.
- **Shared budget tracking** — Combined spending view across members.
- **Member allowances** — Set spending limits per member.
- **Role-based access** — Admin vs. member permissions.
- **Category breakdown** — See combined family spending by category.

### 🏆 Gamification
- **Achievement system** — Unlock badges for milestones (e.g., "First Expense", "Budget Master").
- **Daily streaks** — Track consecutive days of expense logging.
- **Streak widget** in sidebar — Motivates daily engagement.
- Persistent tracking via `user_achievements` and `user_streaks` tables.

### ⚙️ Settings
- **Profile management** — Update display name and avatar.
- **Subscription management** — Pro and Team tiers via Stripe.
- **Theme toggle** — Light/dark mode with system preference detection.

### 🔐 Authentication
- **Email/password** sign-up and sign-in.
- **Google OAuth** sign-in.
- **Password reset** flow.
- **Email verification** required before sign-in.
- Protected routes — All app pages require authentication.

### 🌐 Landing Page
- **3D animated hero** section using Three.js / React Three Fiber.
- Feature showcase, stats counter, testimonials, and pricing section.
- Responsive design with mobile hamburger menu.
- Smooth scroll animations via Framer Motion.

## 🏗 Architecture

```
┌─────────────────────────────────────────────────────┐
│                    Frontend (React)                  │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌────────┐ │
│  │ Pages    │ │Components│ │  Hooks   │ │  Utils │ │
│  └────┬─────┘ └────┬─────┘ └────┬─────┘ └────────┘ │
│       │             │            │                    │
│       └─────────────┴────────────┘                   │
│                     │                                │
│          ┌──────────┴──────────┐                     │
│          │  Supabase Client    │                     │
│          └──────────┬──────────┘                     │
└─────────────────────┼───────────────────────────────┘
                      │
         ┌────────────┴────────────┐
         │     Lovable Cloud       │
         │  ┌─────────────────┐    │
         │  │   PostgreSQL    │    │
         │  │   (Database)    │    │
         │  └─────────────────┘    │
         │  ┌─────────────────┐    │
         │  │ Edge Functions  │    │
         │  │ (Serverless)    │    │
         │  └─────────────────┘    │
         │  ┌─────────────────┐    │
         │  │  Auth + Storage │    │
         │  └─────────────────┘    │
         └─────────────────────────┘
```

### Data Flow

1. **User authenticates** via email/password or Google OAuth.
2. **Frontend** queries PostgreSQL directly via Supabase client (with RLS enforcing row-level security).
3. **AI features** call Edge Functions, which use Lovable AI gateway to access Gemini models.
4. **Payments** flow through Stripe via Edge Functions (create-checkout, customer-portal, check-subscription).

## 🔐 Authentication

- **Provider**: Lovable Cloud Auth (Supabase Auth)
- **Methods**: Email/password, Google OAuth
- **Email verification**: Required (no auto-confirm)
- **Session**: Persisted in localStorage with auto-refresh
- **Protected routes**: Wrapped in `<ProtectedRoute>` component
- **Profile creation**: Automatic via `handle_new_user()` database trigger

### Auth Flow
```
User visits /auth → Signs up with email/password or Google
  → Email verification sent (email/password only)
  → User verifies email → Signs in
  → Redirected to /dashboard
  → Session persisted, auto-refreshed
```

- `is_family_member(user_id, group_id)` — Check group membership
- `is_family_admin(user_id, group_id)` — Check admin role

- `update_updated_at_column()` — Auto-update timestamps

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ and npm

### Local Development

```bash

git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>

# Install dependencies
npm install
```

## 🌍 Deployment

### Via Lovable
1. Open your project in [Lovable](https://lovable.dev).
2. Click **Share → Publish**.
3. Your app is live on a `.lovable.app` subdomain.

### Custom Domain
1. Navigate to **Project → Settings → Domains**.
2. Click **Connect Domain** and follow DNS instructions.

> **Note**: Backend changes (Edge Functions, database migrations) deploy automatically. Frontend changes require clicking "Update" in the publish dialog.
